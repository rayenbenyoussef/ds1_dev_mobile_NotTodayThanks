## Project Overview
Not Today Thanks is an Android application developed as part of a university project. The project aims to provide a simple mobile experience built with Android native technologies, following clean project structure and modern Android app development practices.

## App Information
- Project name: Not Today Thanks
- Platform: Android
- Language: Java
- Architecture: Native Android app
- Build system: Gradle with Kotlin DSL

## Getting Started
1. Open the project in Android Studio.
2. Let Gradle sync the project dependencies.
3. Choose an emulator or connected device.
4. Run the app from the `app` module.

## Build Requirements
- Android Studio latest stable version recommended
- JDK 11 or later
- Android SDK with API level 36 configured
